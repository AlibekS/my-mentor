# grep: найти иголку в логе

`grep` — главный инструмент L3. Он печатает строки, в которых встречается шаблон.

```
grep ERROR /var/log/app/app.log
```

## Флаги, которые нужны каждый день

| Флаг | Что делает | Пример |
|---|---|---|
| `-i` | без учёта регистра (ignore case) | `grep -i error` найдёт ERROR, Error, error |
| `-n` | номера строк | `grep -n FATAL app.log` → `1532:FATAL ...` |
| `-v` | инвертировать: строки **без** шаблона | `grep -v /health access.log` — убрать health-check шум |
| `-c` | посчитать совпадения (count) | `grep -c " 502 " access.log` → `37` |
| `-E` | расширенные regex: `|`, `+`, `?`, `()` | `grep -E "ERROR|FATAL"` |
| `-r` | рекурсивно по каталогу | `grep -r "db-prod-01" /etc` |
| `-l` | только имена файлов | `grep -rl password /opt/app` |
| `-w` | слово целиком | `grep -w 500` не найдёт `1500` |
| `-o` | только совпавшую часть | `grep -o "user_id=[0-9]*"` |
| `-A N`, `-B N`, `-C N` | N строк после/до/вокруг | `grep -A 5 Exception` — стек-трейс |

Флаги склеиваются: `grep -in timeout`.

## Кавычки

Если в шаблоне пробелы или спецсимволы — бери в кавычки:
```
grep " 502 " access.log           # пробелы вокруг, чтобы не поймать 5021 байт
grep 'status=5..' app.log         # . — любой символ
```

## Код выхода grep

- `0` — нашёл, `1` — не нашёл, `2` — ошибка (нет файла).

Удобно в скриптах: `grep -q ERROR app.log && echo "есть ошибки"` (`-q` — тихо, только код выхода).

## Как это выглядит на реальной работе L3

Жалоба: «пользователь user_id=8812 не может оплатить». Ты:
```
grep -c "user_id=8812" app.log            # есть ли вообще его запросы
grep "user_id=8812" app.log | grep -i error   # только ошибки
grep -n "user_id=8812" app.log | tail -3      # последние попытки с номерами строк
```
Через минуту видно: `ERROR card declined by issuer` — это не баг, а отказ банка. Отвечаешь клиенту за 5 минут, а не за час.

## Типичные ошибки

- `grep error` без `-i` — пропустишь все `ERROR`.
- `grep 500` — поймаешь `15000` байт и `500ms`. Добавляй контекст: `" 500 "` или `-w`.
- Забыть, что `-c` считает **строки**, а не вхождения.
