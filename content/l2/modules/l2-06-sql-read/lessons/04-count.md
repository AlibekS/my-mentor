# COUNT, SUM, GROUP BY: посчитать

Частые вопросы к L2: «**сколько** неоплаченных заказов за сегодня?», «**на какую сумму** прошли оплаты?», «какая ошибка оплаты встречается **чаще всего**?». Считать строки глазами долго и ненадёжно — пусть посчитает база.

## COUNT — сколько строк

```sql
SELECT COUNT(*) FROM orders;                         -- всего заказов
SELECT COUNT(*) FROM orders WHERE status = 'unpaid'; -- сколько неоплаченных
```

`COUNT(*)` возвращает **одно число** — количество строк, которые прошли через WHERE.

- `COUNT(*)` — считает строки.
- `COUNT(столбец)` — считает строки, где в этом столбце **не NULL**. `COUNT(assignee)` — сколько тикетов с исполнителем.
- `COUNT(id)` даёт то же, что `COUNT(*)`: id никогда не бывает пустым.

## SUM — сумма

```sql
SELECT SUM(total) FROM orders WHERE status = 'paid';  -- выручка по оплаченным
```

Ещё есть `AVG` (среднее), `MIN` и `MAX` (минимум и максимум). Все они — **агрегатные функции** (aggregate functions): много строк на входе → одно число на выходе.

## «За сегодня»

Время в базе — текст вида `'2026-11-05 10:32:49'`, «сегодня» — 5 ноября 2026 (UTC):

```sql
SELECT COUNT(*) FROM orders
WHERE status = 'unpaid' AND created_at LIKE '2026-11-05%';
```

Можно и так: `created_at >= '2026-11-05'` или `date(created_at) = '2026-11-05'` — результат одинаковый.

> Помни про часовой пояс: «сегодня» клиента в Алматы (UTC+5) и в Нью-Йорке начинается в разное время. В базе — UTC.

## GROUP BY — посчитать по группам

Сколько заказов **в каждом** статусе? Можно четыре раза написать `COUNT(*) … WHERE status = …`, а можно одним запросом:

```sql
SELECT status, COUNT(*)
FROM orders
GROUP BY status;
```

| status | COUNT(*) |
|---|---|
| cancelled | 8 |
| paid | 41 |
| … | … |

`GROUP BY status` раскладывает строки по «кучкам» с одинаковым статусом, а `COUNT(*)` считает каждую кучку отдельно.

Правило: в `SELECT` рядом с `COUNT`/`SUM` пиши только те столбцы, которые перечислены в `GROUP BY`.

WHERE работает **до** группировки — сначала отбираем строки, потом группируем:

```sql
SELECT error_code, COUNT(*) FROM payments
WHERE status = 'failed'
GROUP BY error_code;
```

## Имена столбцов: AS

`COUNT(*)` в заголовке выглядит некрасиво. Можно дать имя: `SELECT status, COUNT(*) AS orders_count FROM orders GROUP BY status;`. На результат (числа) это не влияет.

## Как это выглядит в работе

Руководитель смены спрашивает в чате: *«How many unpaid orders do we have today?»* Ты не гадаешь, а отвечаешь цифрой из запроса и добавляешь, **как** считал: «4 unpaid orders today (UTC), query: status = 'unpaid' and created today». Если цифра необычно большая — это повод проверить, нет ли массовой проблемы с оплатой, и сообщить L3.

## 🇬🇧 English corner

- *How many …?* — Сколько …? (*How many orders?*)
- *How much …?* — Сколько (денег) …? (*How much did we earn today?*)
- *in total* — всего, в сумме
- *per status / per day* — по каждому статусу / за каждый день
