# Что такое DevTools и как попросить о нём клиента

Клиент пишет: «Дашборд не грузится». Скриншот показывает серый блок и надпись *Something went wrong*. По скриншоту причину не найти: он показывает **результат**, а не то, **что произошло внутри**. Внутри браузер сделал десятки запросов к серверам — и один из них, скорее всего, вернул ошибку. Увидеть эти запросы позволяют **инструменты разработчика (DevTools)**.

## Что это такое

DevTools — встроенная в каждый браузер (Chrome, Edge, Firefox, Safari) панель, где видно, что делает страница:

| Вкладка | Что показывает | Когда нужна L2 |
|---|---|---|
| **Network** (Сеть) | все запросы страницы: адрес, статус, время, ответ сервера | «не грузится», «ошибка», «долго» |
| **Console** (Консоль) | ошибки JavaScript и сообщения сайта | «кнопка не нажимается», «пустой экран» |
| **Application** (Приложение) | куки, localStorage, кэш | «выкидывает из аккаунта», «у меня не так, как у коллег» |

Сегодня — первое знакомство с **Network**. Остальные вкладки — в следующих уроках.

## Как открыть

- **Windows / Linux:** `F12` или `Ctrl+Shift+I` (Chrome, Edge, Firefox).
- **Mac:** `Cmd+Option+I`. В Safari сначала включить меню «Разработка» в настройках.
- Или правой кнопкой по странице → **Просмотреть код** / **Inspect**.

Важно: Network записывает запросы, только **пока DevTools открыт**. Поэтому порядок такой:

1. Открыть DevTools → вкладка **Network**.
2. Поставить галочку **Preserve log** (не очищать список при переходах между страницами).
3. **Обновить страницу** (`F5`) или повторить действие, которое ломается.
4. Сделать скриншот всей панели Network или сохранить HAR-файл (про HAR — в уроке 5).

## Таблица Network — колонки

```
Name                 Status  Method  Type      Size     Time
dashboard            200     GET     document  18.4 kB  132 ms
app.5f02bc.js        200     GET     script    262 kB   141 ms
me                   200     GET     fetch     612 B    88 ms
sales?period=7d      500     GET     fetch     498 B    1.21 s   ← красная строка
```

- **Name** — последняя часть адреса (полный адрес — во всплывающей подсказке и в деталях).
- **Status** — код ответа сервера: `2xx` — успех, `3xx` — перенаправление или кэш, `4xx` — ошибка запроса (нет прав, не найдено, неверные данные), `5xx` — ошибка на сервере. `(failed)` — ответа нет вообще.
- **Method** — `GET` (получить данные), `POST` (создать/отправить), `PUT`/`PATCH` (изменить), `DELETE` (удалить).
- **Type** — что загружено: `document` (сама HTML-страница — всегда первая), `script`, `stylesheet`, `img`, `font`, `fetch`/`xhr` (запросы к API — самые интересные для поддержки).
- **Size** и **Time** — размер ответа и сколько длился запрос.
- **Waterfall** — «водопад»: когда запрос начался и сколько шёл относительно других.

Ошибочные запросы DevTools подсвечивает **красным**. Кнопка-фильтр **Fetch/XHR** оставляет только запросы к API, а строка поиска — запросы, где в адресе есть нужное слово.

Клик по строке открывает детали: **Headers** (адрес, метод, статус, заголовки), **Payload** (что отправил браузер), **Response** (что ответил сервер), **Timing** (из чего сложилось время).

## Как попросить клиента

Клиент — не разработчик. Просьба должна быть короткой, по шагам, с извинением за беспокойство:

> Чтобы быстрее найти причину, пожалуйста:
> 1. Нажмите F12 — справа или снизу откроется панель.
> 2. Выберите вкладку **Network**.
> 3. Обновите страницу (F5) и дождитесь ошибки.
> 4. Пришлите скриншот всей панели.

## Как это выглядит в тикете

Без DevTools: «Клиент говорит, дашборд не работает». С DevTools: «`GET /api/v2/reports/sales?period=7d` возвращает **500**, остальные запросы — 200. Ошибка только у виджета продаж». Вторую фразу L3 может взять в работу сразу.

## 🧭 В тренажёре

Справа — DevTools «браузера клиента». Вкладка Network уже записала загрузку страницы. Кликай по строкам, пробуй фильтры «Fetch/XHR» и «Ошибки».

## 🇬🇧 English corner

- *Could you open DevTools (press F12) and go to the Network tab?* — Не могли бы вы открыть DevTools (F12) и перейти на вкладку Network?
- *Please reload the page and send us a screenshot.* — Пожалуйста, обновите страницу и пришлите скриншот.
- *Which browser do you use?* — Каким браузером вы пользуетесь?
- *The request failed with status 500.* — Запрос завершился ошибкой со статусом 500.
- *failed request* — упавший запрос; *status code* — код ответа.
