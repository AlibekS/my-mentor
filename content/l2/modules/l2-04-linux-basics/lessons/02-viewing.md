# Читаем файлы: cat, less, head, tail, wc

Ты нашёл нужный каталог. Теперь главное — **прочитать** файл: настройку в конфиге или последние события в логе. Для этого в Linux есть несколько команд, и у каждой своя задача.

## cat — показать файл целиком

`cat` (от concatenate — «склеить») выводит весь файл на экран:

```
$ cat /etc/shop/app.conf
# Shop application config
app_name=shop
port=8080
```

Удобно для **маленьких** файлов: конфигов, заметок, тикетов. Строки, которые начинаются с `#`, — комментарии, программа их не читает.

> Не запускай `cat` на огромном логе: на экран вывалятся тысячи строк. Для больших файлов — `less`, `head`, `tail`.

## less — листать большой файл

`less файл` открывает файл постранично, как книгу:

| Клавиша | Действие |
|---|---|
| пробел / `PgDn` | следующая страница |
| `b` | предыдущая страница |
| `/слово` + Enter | найти слово (`n` — следующее совпадение) |
| `G` / `g` | в конец / в начало файла |
| `q` | **выйти** |

В тренажёре `less` показывает первые 40 строк — этого хватит, чтобы привыкнуть.

## head — начало файла

`head` (голова) показывает **первые** 10 строк. Сколько строк — задаёт флаг `-n`:

```
head /var/log/shop/app.log          # первые 10 строк
head -n 5 /var/log/shop/app.log     # первые 5 строк
head -5 /var/log/shop/app.log       # то же самое, короче
```

**Флаг** (option) — это настройка команды, начинается с минуса: `-n 5`.

## tail — конец файла

`tail` (хвост) показывает **последние** строки. В логах новые события дописываются в конец, поэтому `tail` — главная команда поддержки:

```
tail /var/log/shop/app.log          # последние 10 строк
tail -n 3 /var/log/shop/app.log     # последние 3 строки
```

Есть ещё `tail -f` — «следить» за файлом в реальном времени. Подробно — в модуле про логи.

## wc -l — сколько строк

`wc` (word count) считает строки, слова и символы. С флагом `-l` (lines) — только строки:

```
$ wc -l /var/log/shop/app.log
1250 /var/log/shop/app.log
```

Число строк в логе — это примерно «сколько событий записано».

## Вывод одной команды — на вход другой

Иногда вывод удобно передать следующей команде через **пайп** `|` (вертикальная черта):

```
cat /var/log/shop/app.log | wc -l     # посчитать строки
cat /var/log/shop/app.log | head -5   # первые 5 строк
```

Результат тот же, что у `wc -l файл` и `head -5 файл`. Подробно про пайпы — в модуле про логи.

## Какую команду выбрать

| Задача | Команда |
|---|---|
| маленький конфиг или заметка | `cat` |
| большой файл, полистать и поискать | `less` |
| как начинается файл | `head` |
| что случилось **последним** | `tail` |
| сколько строк | `wc -l` |

## Частые ошибки

- `cat` на файле в гигабайт — терминал «зависнет». Нажми `Ctrl+C`, чтобы остановить вывод.
- Застрял в `less` — нажми `q`.
- Забыл путь: `head -5` без имени файла ждёт ввода с клавиатуры. Выйди через `Ctrl+C`.

## Как это выглядит в тикете

Клиент: «оплата не проходит последние 10 минут». Ты открываешь конец лога: `tail -n 20 /var/log/shop/app.log` и видишь `ERROR Payment gateway timeout`. В тикет копируешь **точную строку** из лога с временем — это лучше, чем пересказ «там какая-то ошибка оплаты».

## 🇬🇧 English corner

Сообщения в логах почти всегда на английском. Частые слова:

- *timeout* — превышено время ожидания (ответ не пришёл вовремя).
- *no response from …* — нет ответа от …
- *failed* — не удалось; *succeeded* — удалось.
- *gateway* — шлюз (например, платёжный шлюз — payment gateway).
- *Here are the last lines from the log.* — Вот последние строки из лога.
