# grep: найти нужные строки

В настоящем логе — тысячи строк. Листать их глазами бесполезно. `grep` делает за тебя самое важное: **оставляет только строки, где есть нужное слово**. Это, пожалуй, самая полезная команда для поддержки.

## Как работает grep

```
grep ЧТО_ИСКАТЬ ГДЕ_ИСКАТЬ
```

```
$ grep ERROR /var/log/shop/app.log
2026-11-04 11:05:40 ERROR order=ORD-1042 user=u-311 Payment failed: card declined
2026-11-04 11:21:16 ERROR order=ORD-1057 user=u-318 Payment failed: insufficient funds
```

`grep` прочитал файл и вывел только строки, в которых есть `ERROR`. Остальные строки он не трогает — файл не меняется.

Если ничего не найдено, `grep` молча ничего не выводит. Это не поломка, а ответ: «таких строк нет».

## Ищем по номеру заказа или пользователя

В тикете почти всегда есть зацепка: номер заказа, email, id пользователя. Ищем по ней:

```
grep ORD-1042 /var/log/shop/app.log      # всё про заказ ORD-1042
grep user=u-311 /var/log/shop/app.log    # всё про пользователя u-311
```

Если в шаблоне есть пробелы или спецсимволы, возьми его в кавычки:

```
grep "card declined" /var/log/shop/app.log
```

## Регистр букв: флаг -i

`grep` различает большие и маленькие буквы: `timeout`, `Timeout` и `TIMEOUT` для него — три разных слова. Флаг `-i` (ignore case — «не обращать внимания на регистр») ищет все варианты:

```
grep -i timeout /var/log/shop/app.log
```

## Посчитать: флаг -c

Иногда нужны не сами строки, а **сколько их**. Флаг `-c` (count):

```
$ grep -c ERROR /var/log/shop/app.log
2
```

То же самое можно сделать через пайп: `grep ERROR файл | wc -l`.

Флаги можно склеивать: `grep -ic timeout файл` — посчитать без учёта регистра.

## Полезные флаги на будущее

| Флаг | Что делает |
|---|---|
| `-i` | без учёта регистра |
| `-c` | посчитать строки |
| `-n` | показать номер строки |
| `-v` | показать строки, где слова **нет** (подробно — в модуле про логи) |

## Частые ошибки

- Перепутать порядок: сначала **что** ищем, потом **где**. `grep app.log ERROR` будет искать слово «app.log» в файле «ERROR».
- Искать `error`, когда в логе пишут `ERROR`. Не нашёл — попробуй `-i`.
- Забыть кавычки вокруг фразы с пробелом: `grep card declined файл` ищет `card` в файлах `declined` и `файл`.

## Как это выглядит в тикете

Тикет: «I can't pay for order ORD-1042». Ты делаешь `grep ORD-1042 /var/log/shop/app.log` и видишь всю историю заказа: создан, открыта оплата, `Payment failed: card declined`. Теперь можно ответить клиенту по существу: банк отклонил карту — попробуйте другую карту или свяжитесь с банком. А в тикет — строки лога как доказательство.

## 🇬🇧 English corner

Как клиенты пишут о проблеме с оплатой:

- *I can't pay for my order.* — Не могу оплатить заказ.
- *My card was declined.* — Мою карту отклонили.
- *I tried three times.* — Я пробовал три раза.
- *The order is stuck.* — Заказ «завис».
- *insufficient funds* — недостаточно средств на карте.
